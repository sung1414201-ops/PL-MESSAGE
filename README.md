# PL-MESSAGE

학원(특강) 성적 관리 및 학생/학부모 안내 문자 자동 생성을 위한 웹 도구 모음입니다. 각 페이지는 순수 HTML/JS로 작성되었고, 데이터는 Google Apps Script 기반 백엔드 API를 통해 읽고 씁니다.

## 파일 구성

- `index.html` — 특강 과목/학생 명단을 관리하고, 회차별 시험 점수를 입력하면 학생별 성적 통보 문자를 자동으로 생성해줍니다.
- `student_view.html` — 학생이 본인 코드를 입력해 주간/월간 성적 추이와 선생님 코멘트를 조회하는 페이지입니다.
- `teacher_dashboard.html` — 반별로 그룹화된 전체 학생의 최근 성적을 한눈에 확인하는 교사용 대시보드입니다.
- `teacher_input.html` — 교사가 학생별 주간/월간 시험 기록과 특징 태그, 코멘트를 입력/수정하는 페이지입니다.

## 실행 방법

별도의 빌드 과정 없이, 각 HTML 파일을 브라우저로 열거나 GitHub Pages로 배포해서 바로 사용합니다.
